# Embedded fonts

Both faces are subset per-SVG at build time and inlined as base64 `@font-face`
data URIs, so the artwork renders identically on every machine and fetches
nothing from a CDN.

- **Inter** — SIL Open Font License 1.1 — https://github.com/rsms/inter
- **JetBrains Mono** — SIL Open Font License 1.1 — https://github.com/JetBrains/JetBrainsMono

The OFL permits embedding in documents; these files are redistributed unmodified.
